# Small Yokohama 全体タイル計画 & チーム分担ガイド

## 1. カメラ・タイル仕様（全担当者共通・固定値）

| 項目 | 値 |
| --- | --- |
| カメラ投影 | 正射影アイソメトリック（`azimuth = 225°`, `depression = 45°`：沖合北東から南西見下ろし） |
| 地上解像度 | `0.34 m/px` |
| 作業タイルサイズ | `2048 × 2048 px`（実寸 `696.3 m × 696.3 m`） |
| オーバーラップ | `128 px`（14px DP 最小色差シーム合成で自動接続） |
| タイル歩進幅 (stride) | `1920 px`（実寸 `652.8 m`） |
| 原点基準 | 現在の先行4タイル（新港パイロット）を `col ∈ {0, 1}, row ∈ {0, 1}` に固定（`originPx = (col × 1920, row × 1920)`） |
| 航空写真ソース | 国土地理院 シームレス空中写真 `z=18` |

> [!NOTE]
> `row = 0..1` において、カメラ角度（`225°`）の都合上、**`col` が小さい側（負方向）が南東・元町/山下公園方面**、**`col` が大きい側（正方向）が北西・みなとみらい/横浜駅方面**へ進みます。同様に **`row = -1` が内陸側**、**`row = +1` が海側**です。

## 6. 複数人で画風・位置を揃えるための 5 箇条

1. **スタイル参照元は全員必ず `data/drawn-tiles/tile_1_1.png`（#1）1枚に固定する**  
   隣タイル（例：`tile_2_0` を作る際に `tile_1_0` を参照する等）を連鎖的に参照すると線幅・彩度・暖色寄りが徐々にドリフトします。**レイアウトベースは自タイルの `_base.png`、画風参照は常に `tile_1_1.png`** に固定してください。
2. **128px 重複帯は 14px DP 最小色差シーム合成で自動接続するため完全並列制作が可能**  
   各タイルが独立しているため、担当 1〜5 が待機なしで同時並行にイラスト生成を進められます。
3. **水面（海・運河・河川）の色・質感を `#226276` に統一する**  
   港湾水面だけでなく運河・川（中村川・大岡川・帷子川河口等）も茶褐色航空写真のままとせず、すべて `tile_1_1.png` と同じ `#226276` ティールブルー＋繊細な水平インク波紋で統一します。
4. **受入 QA 基準を数値でゲートする**  
   `build:pilot`（または拡張ビルド）実行時の Sobel 相関で **`|shiftDx|, |shiftDy| <= 8 px`**、**`edgeCorr >= 0.70`**、シームチェック **`meanColorDiff < 48`**、水域捏造 **`waterInventedBuildings === 0`** を必須とします。
5. **1 担当ブロック = 1 ブランチ / 1 PR で運用してコンフリクトゼロにする**  
   各担当者は `data/drawn-tiles/tile_{col}_{row}.png` と `data/drawn-tiles/tile_{col}_{row}_meta.json` だけを追加して PR を出せば、互いにファイル競合を起こさずマージできます（共通基盤側の更新も `render:tile` により完了済みです）。

## 7. ベースタイル生成・セルフ QA コマンド

各担当者はブロック名（または任意の `<col>,<row>`）を指定して国土地理院 `z=18` 空中写真の取得と `_base.png` 出力を実行できます。イラスト（`data/drawn-tiles/tile_{col}_{row}.png`）配置後に同じコマンドを再実行すると、Sobel 相関（`shift`, `edgeCorr`）と `_overlay_check.png` も出力されます。

```powershell
# 担当ブロック単位で _base.png を一括生成（Windows PowerShell / macOS・Linux は npm）
npm.cmd run render:tile -- --block phase-a-1
npm.cmd run render:tile -- --block phase-a-2
npm.cmd run render:tile -- --block phase-a-3
npm.cmd run render:tile -- --block phase-b-1
npm.cmd run render:tile -- --block phase-b-2

# 単一タイルを指定して生成・位置ズレ自己検証
npm.cmd run render:tile -- --tile 2,0
```
